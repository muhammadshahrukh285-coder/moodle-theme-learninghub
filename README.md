# Learning Hub – Moodle 4.5 Theme

A modern, responsive Moodle theme designed for a professional Learning Management System (LMS).

Learning Hub focuses on a clean, professional learner experience while maintaining Moodle's native functionality and extensibility.

## Features

- Moodle 4.5 compatible
- Responsive design
- Custom Learning Hub branding
- Premium custom login page
- Custom front page
- Configurable logo and favicon
- Custom theme settings
- Modular SCSS architecture
- Custom renderer overrides
- Responsive navigation styling
- Moodle Boost parent theme integration
